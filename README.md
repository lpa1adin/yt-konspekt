# YT-Конспект

**YT-Конспект** — локальное веб-приложение, которое делает конспект YouTube-видео. Вы вставляете ссылку,
а через несколько минут получаете структурированный конспект: краткое содержание, разделы с таймкодами,
ключевые термины и выводы. Клик по таймкоду перематывает видео в плеере рядом с конспектом.

По умолчанию всё работает **на вашем компьютере**: текст видео берётся из субтитров YouTube или распознаётся
локальной моделью Whisper, конспект пишет локальная языковая модель через [Ollama](https://ollama.com)
(или LM Studio). Регистрации и подписок не нужно, в интернет приложение ходит только к YouTube.

Если хочется качества выше или компьютер слабый, конспект может писать **облачная модель** — Claude, ChatGPT,
Gemini, DeepSeek, Mistral или любая из сотен моделей OpenRouter. Для этого нужен ключ API провайдера.

Сделано под Mac на Apple Silicon (M1–M4) с 16 ГБ памяти, работает также на Windows и Linux.

## Что умеет

- **Конспект по ссылке.** Одна или несколько ссылок сразу (по одной на строку): `youtu.be/…`, `watch?v=…`,
  `shorts/…`, `live/…`, `embed/…`.
- **Очередь задач с живым прогрессом.** Видно этап (субтитры → аудио → распознавание в % → «часть 3 из 8» →
  сохранение файла) и текст, который модель пишет прямо сейчас. Задачу можно отменить или повторить:
  повтор продолжает с места, где она остановилась.
- **Библиотека.** Все конспекты с обложками, полнотекстовый поиск по конспектам *и* расшифровкам
  с подсветкой совпадений, фильтры по каналу и дате.
- **Страница конспекта.** Слева конспект и вкладка «Расшифровка», справа плеер YouTube. Клик по таймкоду
  перематывает видео, текущий фрагмент расшифровки подсвечивается.
- **Переделка без повторного распознавания.** Можно пересоставить конспект другой моделью, на другом языке
  или в другой подробности: расшифровка уже сохранена, поэтому это занимает минуты.
- **Версии и ручная правка.** Каждая переделка и каждая ручная правка — новая версия, старые не теряются.
- **Экспорт** в `.md`, `.docx` и `.pages` (Pages — только macOS), кнопки «Открыть файл» и «Показать в папке».
  Таймкоды в файлах остаются рабочими ссылками на YouTube.
- **Экран «Состояние»** проверяет, всё ли установлено, подсказывает, как починить, и умеет скачать модель.

## Как это работает

```
ссылка
  │
  ├─ 1. yt-dlp: название, канал, длительность, список субтитров
  │
  ├─ 2. Текст видео
  │     ├─ есть субтитры → берём их (ручные на языке видео → ручные ru/en →
  │     │                  оригинальная автодорожка → автосубтитры)
  │     └─ нет субтитров → скачиваем аудио → Whisper large-v3-turbo
  │                        (mlx-whisper на Mac M, faster-whisper на остальных)
  │
  ├─ 3. Расшифровка → блоки по ~30 секунд вида «[мм:сс] текст»
  │
  ├─ 4. Языковая модель пишет конспект (Ollama с qwen3:8b по умолчанию
  │     или облачная: Claude, ChatGPT, Gemini…)
  │     ├─ короткое видео → один запрос
  │     └─ длинное (> ~30–40 минут речи) → конспект каждой части по ~25 минут;
  │        эти части целиком становятся разделом «Конспект», а итоговый запрос
  │        пишет по ним «Кратко», «Ключевые термины» и «Выводы»
  │
  ├─ 5. Таймкоды [мм:сс] превращаются в ссылки https://youtu.be/ID?t=секунды,
  │     сверху добавляется шапка (видео, канал, длительность, модель, источник текста)
  │
  └─ 6. Конспект сохраняется в библиотеку и (если включено) в файл в выбранной папке
```

Важные решения внутри:

- **Задачи выполняются строго по одной.** Whisper (~2 ГБ) и языковая модель (~5–7 ГБ) никогда не работают
  одновременно — иначе на 16 ГБ не хватит памяти. После распознавания Whisper выгружается из памяти,
  а когда очередь пустеет, Ollama тоже освобождает модель.
- **Ничего не выдумывается.** Если в видео почти нет речи (музыка, расшифровка короче ~200 символов),
  задача останавливается с сообщением вместо фантазий модели. Промпт велит опираться только на расшифровку
  и исправлять очевидные ошибки распознавания.
- **Ссылки делает код, а не модель.** Модель пишет таймкоды в скобках, приложение проверяет каждый по расшифровке
  (чинит потерянные часы, привязывает к ближайшему реальному моменту) и превращает в ссылку.
- **Длинное видео не ужимается.** Конспект каждой части попадает в документ целиком: 4-часовой курс даёт
  подробный конспект по всем частям, а не короткий пересказ.
- **Ничего не теряется.** Метаданные, расшифровка и уже готовые части конспекта сохраняются по ходу работы.
  Если задача упала на части 5 из 8 или Ollama была выключена, «Повторить» продолжит с пятой части.
- **Один процесс.** Сервер на FastAPI отдаёт страницы и API, фоновый воркер выполняет задачи,
  прогресс приходит в браузер через Server-Sent Events. Данные — в одном файле SQLite.

## Установка

Ниже — пошаговая установка на компьютер, где ещё ничего нет: ни Python, ни Git, ни инструментов разработчика.
Займёт 15–30 минут, большая часть — ожидание загрузки. Команды вводятся в **терминал**. Копируйте их
по одной, вставляйте и нажимайте Enter.

### Что будет установлено

| Программа | Зачем | Обязательно? |
|---|---|---|
| **uv** | ставит нужную версию Python и библиотеки приложения | да |
| **Git** | скачивает приложение с GitHub и обновляет его | да (или скачайте ZIP) |
| **ffmpeg** | режет звук для распознавания речи | да |
| **Deno** (или Node.js) | нужен yt-dlp, чтобы YouTube отдавал звук | да |
| **Ollama** + модель `qwen3:8b` | бесплатная модель на вашем компьютере, ~5 ГБ | нет, если пользуетесь облачной моделью (Claude, ChatGPT, Gemini…) |
| **pandoc** | более аккуратное оформление `.docx` | нет |
| **Pages** | экспорт в `.pages` | нет, только macOS |

Python отдельно ставить не нужно: uv сам скачает подходящую версию (3.11 или новее) при первой команде `uv venv`.

### macOS (Apple Silicon или Intel)

**1. Откройте Терминал.** Cmd+Пробел → наберите «Терминал» → Enter.

**2. Установите Homebrew** — менеджер программ для macOS. Если он уже есть (`brew --version` выводит версию),
пропустите шаг.

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Установщик спросит пароль от Mac (символы при вводе не видны — это нормально) и предложит поставить
Command Line Tools — согласитесь. В конце он напишет «Next steps» с двумя командами — **выполните их**.
На Mac с процессором M они такие:

```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
```

```bash
eval "$(/opt/homebrew/bin/brew shellenv)"
```

**3. Установите программы:**

```bash
brew install git uv ffmpeg deno pandoc
```

**4. Ollama** (пропустите, если будете пользоваться только облачной моделью):

```bash
brew install --cask ollama
```

Запустите приложение **Ollama** из папки «Программы» — в строке меню появится значок ламы.
Затем скачайте модель (≈ 5 ГБ, один раз):

```bash
ollama pull qwen3:8b
```

**5. Скачайте приложение** в домашнюю папку и установите библиотеки:

```bash
cd ~ && git clone https://github.com/lpa1adin/yt-konspekt.git
```

```bash
cd ~/yt-konspekt && uv venv && uv pip install -e ".[dev]"
```

Первая установка скачивает около 1 ГБ (Python, mlx-whisper, yt-dlp и др.).

**6. Запустите:**

```bash
cd ~/yt-konspekt && uv run python -m app
```

Откроется браузер с приложением. Дальше — раздел [Первый запуск](#первый-запуск).

> На Mac с процессором M распознавание речи идёт через **mlx-whisper** на видеокарте, на Intel — через
> **faster-whisper** на процессоре (медленнее).

### Windows 10 и 11

**1. Откройте PowerShell.** Пуск → наберите «PowerShell» → Enter. Права администратора не нужны.

**2. Установите программы** через winget (встроен в Windows 10/11; если команды нет — обновите
«Установщик приложений» в Microsoft Store):

```powershell
winget install --id astral-sh.uv -e; winget install --id Git.Git -e; winget install --id Gyan.FFmpeg -e; winget install --id DenoLand.Deno -e; winget install --id JohnMacFarlane.Pandoc -e
```

Согласитесь с условиями (`Y`). **Закройте PowerShell и откройте заново** — иначе новые команды не найдутся.

**3. Ollama** (пропустите, если будете пользоваться только облачной моделью):

```powershell
winget install --id Ollama.Ollama -e
```

Ollama запустится сама (значок в трее). Скачайте модель:

```powershell
ollama pull qwen3:8b
```

**4. Скачайте и установите приложение:**

```powershell
cd ~; git clone https://github.com/lpa1adin/yt-konspekt.git; cd yt-konspekt; uv venv; uv pip install -e ".[dev]"
```

**5. Запустите:**

```powershell
cd ~\yt-konspekt; uv run python -m app
```

> На Windows речь распознаёт **faster-whisper** на процессоре. Видеокарта NVIDIA ускоряет его в разы, но
> для этого нужны библиотеки CUDA (cuBLAS и cuDNN) — см. документацию faster-whisper.

### Обновление

```bash
cd ~/yt-konspekt && git pull && uv pip install -e ".[dev]"
```

Если YouTube перестал отдавать видео — обычно хватает обновить yt-dlp: `uv pip install -U "yt-dlp[default]"`.

### Удаление

Удалите папку `~/yt-konspekt` и папку данных (см. [Где хранятся данные](#где-хранятся-данные)).
Модели: `ollama rm qwen3:8b` и кэш Whisper в `~/.cache/huggingface`.

## Первый запуск

1. Запустите приложение командой из шага «Запустите». Браузер откроется на **http://127.0.0.1:8765**.
   Терминал не закрывайте — пока он открыт, приложение работает. Остановить — `Ctrl+C`.
2. Откройте **«Состояние»**. Все пункты должны быть зелёными; у красных есть подсказка, что сделать.
3. **Выберите модель** в «Настройки → Модель»:
   - **Ollama** — бесплатно и без интернета, если `ollama pull qwen3:8b` уже выполнен;
   - **облачная модель** — см. [Облачные модели](#облачные-модели-claude-chatgpt-gemini).
4. Вставьте ссылку на видео на главной странице и нажмите Enter.

При первом распознавании речи (видео без субтитров) приложение скачает модель Whisper ≈ 1,6 ГБ — это один раз.

## Запуск

Команды выполняются **из папки проекта** (там, где лежит `pyproject.toml`):

```bash
cd ~/yt-konspekt
uv run python -m app
```

Откроется браузер на **http://127.0.0.1:8765**. Остановить — `Ctrl+C` в терминале.

Параметры запуска:

| Параметр | Что делает |
|---|---|
| `--port 8800` | другой порт |
| `--no-browser` | не открывать браузер автоматически |
| `--window` | открыть в отдельном окне, как приложение (нужно `uv pip install pywebview`) |

Сервер слушает только `127.0.0.1` — с других устройств в сети приложение недоступно.

> Если видите `No module named app` — вы запускаете не из папки проекта. Сначала `cd ~/yt-konspekt`.

### Режим командной строки

Без интерфейса и библиотеки — сразу в файл:

```bash
uv run python -m app.cli "https://youtu.be/VIDEO_ID" -o ~/Desktop/Лекции -f docx --detail short
```

Ключи: `-o` папка, `-f md|docx|pages`, `--detail full|short`, `--lang ru`, `-m qwen3:8b`,
`--whisper` (не брать субтитры), `--transcript` (сохранить и расшифровку), `--open` (открыть файл).

## Как пользоваться

1. **Первый запуск — экран «Состояние».** Пройдите пункты с красной отметкой сверху вниз. Если модели нет,
   нажмите «Скачать модель».
2. **«Новый конспект».** Вставьте ссылку и нажмите Enter (несколько ссылок — по одной на строку,
   новая строка — Shift+Enter). В свёрнутом блоке «Параметры» можно выбрать подробность, язык конспекта,
   модель, формат файла, папку (кнопка «Выбрать…» открывает системный диалог) и «Всегда распознавать речь
   Whisper».
3. **Ждите в карточке задачи.** Видно этап, прогресс и текст, который пишет модель. Время: видео с субтитрами —
   1–3 минуты; без субтитров добавляется распознавание (на Mac M примерно 1 минута на 10 минут видео).
4. **«Готово» → «Открыть».** Страница конспекта:
   - клик по таймкоду перематывает плеер справа;
   - вкладка «Расшифровка» — полный текст, текущий фрагмент подсвечивается («следовать за видео»);
   - **«Переделать»** — новая версия с другой моделью, языком или подробностью (без повторного Whisper);
   - **«Редактировать»** — правка в Markdown, сохраняется новой версией;
   - выбор версии — выпадающий список сверху;
   - **«Экспорт»**, «Показать в папке», «Удалить» (файлы на диске при удалении не трогаются).
5. **«Библиотека».** Поиск по любому слову из конспекта или расшифровки, фильтр по каналу и периоду.

Если ссылку на видео, которое уже есть в библиотеке, вставить ещё раз, приложение предупредит и предложит
открыть существующий конспект или всё же сделать новую версию.

## Настройка

Всё основное меняется на экране **«Настройки»**:

| Раздел | Что настраивается |
|---|---|
| Сохранение файлов | папка по умолчанию, формат, «сохранять файл сразу после готовности», шаблон имени (`{title}`, `{date} {title}`, `{channel}/{title}`), оставлять ли `.md` рядом, шаблон стилей `.docx` |
| Конспект | язык (по умолчанию русский), подробный или краткий |
| Модель (LLM) | где работает модель (Ollama, LM Studio или облачный API), ключ API, адрес, модель, контекст `num_ctx` (Ollama), размер части `chunk_chars`, температура, глубина рассуждений Claude |
| Распознавание речи | движок (авто / mlx / faster), модель Whisper (large-v3-turbo / medium / small), язык речи, языки субтитров, брать ли субтитры YouTube, хранить ли аудио |
| YouTube | «Cookies из браузера» — если YouTube просит войти или подтвердить, что вы не бот |
| Промпты | тексты запросов к модели, у каждого — «Сбросить к умолчанию» |

### Выбор модели

Подходит любая модель из Ollama — список берётся из того, что у вас скачано. По умолчанию `qwen3:8b`:
хорошо пишет по-русски и помещается в 16 ГБ. На 32 ГБ и больше можно попробовать `qwen3:14b` или
`gemma3:12b` (скачать — на экране «Состояние» или `ollama pull имя`).

Для **LM Studio**: в LM Studio Developer → Start Server, в настройках выберите «LM Studio / llama.cpp
(локально)» — адрес `http://localhost:1234/v1` подставится сам.

### Облачные модели (Claude, ChatGPT, Gemini…)

Вместо локальной модели конспект может писать облачная. Это удобно, если компьютер слабый или памяти меньше
16 ГБ, и даёт заметно более качественные конспекты длинных лекций. Распознавание речи (Whisper) при этом
всё равно идёт на вашем компьютере.

| Провайдер | Модель по умолчанию | Где взять ключ |
|---|---|---|
| Claude (Anthropic) | `claude-opus-5-5` | [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) |
| ChatGPT (OpenAI) | `gpt-5-mini` | [platform.openai.com/api-keys](https://platform.openai.com/api-keys) |
| Gemini (Google) | `gemini-2.5-flash` | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| OpenRouter — сотни моделей по одному ключу | любая из списка | [openrouter.ai/keys](https://openrouter.ai/keys) |
| DeepSeek | `deepseek-chat` | [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys) |
| Mistral | `mistral-large-latest` | [console.mistral.ai/api-keys](https://console.mistral.ai/api-keys) |
| Другой OpenAI-совместимый API | — | у провайдера |

**Как подключить:**

1. Создайте ключ API у провайдера и пополните баланс. Подписка ChatGPT Plus или Claude Pro
   **не подходит** — нужен именно ключ API, он оплачивается отдельно, по объёму текста.
2. В приложении: **«Настройки» → «Модель (LLM)» → «Где работает модель»** — выберите провайдера.
   Адрес и модель подставятся сами.
3. Вставьте ключ в поле «API-ключ» и нажмите «Сохранить».
4. После сохранения в поле «Модель» появится список доступных моделей. Выберите нужную
   и сохраните ещё раз. Проверка — на экране «Состояние».

Ключ хранится только в базе приложения на вашем компьютере, в интерфейсе виден лишь его хвост (`…a1b2`).
Вместо поля можно задать переменную окружения: `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`, `GEMINI_API_KEY`,
`OPENROUTER_API_KEY`, `DEEPSEEK_API_KEY` или `MISTRAL_API_KEY`.

**Что важно знать:**

- **Расшифровка уходит провайдеру.** С облачной моделью текст видео и промпты отправляются на сервер
  выбранной компании. Для приватных записей пользуйтесь Ollama.
- **Стоимость** зависит от модели и длины видео. Часовая лекция — это примерно 15–20 тысяч слов текста,
  4-часовой курс — в 4 раза больше. У недорогих моделей (Claude Haiku, GPT mini, Gemini Flash) это доли цента —
  центы, у старших (Claude Opus, GPT-5) — от десятков центов до пары долларов. Актуальные цены — на сайте
  провайдера.
- **Claude** подключается через официальный SDK Anthropic. Параметр «Глубина рассуждений» (effort):
  `low` — быстрее и дешевле, `high` — тщательнее. Для старших моделей включён серверный запасной вариант:
  если модель откажется обрабатывать фрагмент, Anthropic сам перезапустит запрос на подходящей модели.
- **Остальные** провайдеры работают через OpenAI-совместимый протокол — так можно подключить и любой
  другой сервис с таким API: выберите «Другой OpenAI-совместимый API» и укажите адрес (обычно
  заканчивается на `/v1`).
- Если провайдер ответил «лимит запросов» или сервер недоступен, задача подождёт и продолжит сама.
  Если ключ неверный или кончились деньги — задача остановится с подсказкой.


### Длинные видео

`chunk_chars` (по умолчанию 18 000 символов ≈ 20–25 минут речи) — сколько текста уходит в один запрос.
Если появилось предупреждение «ответ обрезан», уменьшите это число и нажмите «Переделать».
`num_ctx` (по умолчанию 16 384 токена, только Ollama) — размер контекста модели; больше — точнее для длинных
частей, но больше памяти. У облачных моделей контекст огромный, настраивать его не нужно.

### Промпты

Лежат в `app/prompts/` и редактируются в «Настройках» (ваши правки хранятся в базе, файлы не меняются):

| Файл | Назначение |
|---|---|
| `system.md` | роль модели и общие правила |
| `full.md` | структура подробного конспекта (Кратко / Конспект / Ключевые термины / Выводы) |
| `short.md` | структура краткого конспекта (Кратко / Главное / Выводы) |
| `chunk.md` | конспект одной части длинного видео |
| `merge.md` | сведение частей группами |
| `final.md` | итоговый запрос: весь конспект короткого видео или итоговые разделы длинного |

Переменные: `{title}`, `{language}`, `{transcript}`, `{i}`, `{n}`, `{start}` и `{end}` (границы фрагмента), `{structure}`.
Таймкоды модель пишет в квадратных скобках, как в расшифровке (`[12:34]`, `[1:05:30]`), — ссылки из них делает приложение.

### Файл config.toml (необязательно)

Настройки можно задать и файлом — например, чтобы перенести их на другой компьютер. Скопируйте
`config.example.toml` в папку данных под именем `config.toml` (пути — ниже). Порядок применения:
значения по умолчанию → `config.toml` → «Настройки» в интерфейсе → параметры конкретной задачи.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `command not found: brew` / `uv` / `git` | Программа не установлена или терминал не перезапущен после установки. Закройте и откройте терминал; на macOS выполните две команды «Next steps» из установщика Homebrew. |
| `command not found: ollama` | Ollama не установлена — см. [Установка](#установка). Если пользуетесь облачной моделью, Ollama не нужна. |
| `No module named app` | Запускайте из папки проекта: `cd ~/yt-konspekt`. |
| «Нет связи с сервером модели» | Запустите Ollama. Задача подождёт и продолжится сама (или нажмите «Проверить снова»). |
| «В Ollama нет модели …» | «Состояние» → «Скачать модель» или `ollama pull qwen3:8b`. |
| «Не указан API-ключ для …» | «Настройки → Модель» → вставьте ключ провайдера и сохраните. |
| «API-ключ не подошёл» | Ключ скопирован не целиком, отозван или на балансе нет денег. Создайте новый ключ у провайдера. |
| «Сервер занят или лимит запросов» | Облачный провайдер временно ограничил запросы. Задача продолжится сама; если повторяется — проверьте лимиты аккаунта. |
| «Не установлен пакет anthropic» | `uv pip install -e ".[dev]"` в папке приложения. |
| «YouTube просит подтвердить, что вы не бот» | `uv pip install -U yt-dlp`, затем в «Настройках» выберите «Cookies из браузера», где вы вошли в YouTube. |
| «YouTube не отдал звуковую дорожку» / `Requested format is not available` | `uv pip install -U "yt-dlp[default]"` и `brew install deno` (если нет ни Deno, ни Node.js), затем перезапустите приложение. Проверить — на экране «Состояние». |
| «Видео недоступно (закрытое или с возрастным ограничением)» | Та же настройка «Cookies из браузера». |
| «Не удалось прочитать cookies…» / `could not find … cookies database` | macOS не пускает Терминал к данным браузера. «Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску» → включите Терминал и перезапустите его; для Chrome, Edge и Brave разрешите запрос связки ключей. Приложение в этом случае продолжает без cookies — они нужны только для закрытых видео и проверки «не бот». |
| «Сейчас идёт прямой эфир» | Дождитесь окончания эфира. |
| «Ответ модели обрезан» | Уменьшите «Размер части» и нажмите «Переделать». |
| «В видео почти нет речи» | Это музыка или видео без слов — конспект не выдумывается. |
| «Не удалось сохранить файл» | Конспект уже в библиотеке — «Экспорт» в другую папку. |
| Нет связи с YouTube | Приложение само повторяет 2 раза; потом — «Повторить». |

Подробности ошибки — кнопка «Подробнее» в карточке задачи и журнал `logs/app.log` в папке данных.

## Где хранятся данные

Данные лежат **вне папки проекта**:

| Что | Где |
|---|---|
| База (библиотека, расшифровки, версии, настройки, ключи API, задачи) | `konspekt.sqlite3` в папке данных |
| Журнал | `logs/app.log` в папке данных |
| Временное аудио (удаляется после распознавания) | `cache/` в папке данных |
| Модели Whisper | кэш Hugging Face (`~/.cache/huggingface`) |
| Модели Ollama | `~/.ollama` |
| Файлы конспектов | выбранная папка, по умолчанию `~/Documents/Конспекты` |

Папка данных: macOS — `~/Library/Application Support/yt-konspekt`, Windows — `%LOCALAPPDATA%\yt-konspekt`,
Linux — `~/.local/share/yt-konspekt`. Другую можно указать переменной окружения `YT_KONSPEKT_DATA`.

```
yt-konspekt/
├── app/
│   ├── __main__.py        # python -m app → сервер + браузер
│   ├── main.py            # FastAPI: страницы и JSON API

│   ├── jobs.py            # очередь и воркер: задачи строго по одной
│   ├── events.py          # шина событий для SSE
│   ├── status.py          # проверки экрана «Состояние»
│   ├── cli.py             # режим командной строки
│   ├── pipeline/          # шаги без БД и веба
│   │   ├── source.py      #   yt-dlp: ID, метаданные, субтитры, аудио, понятные ошибки
│   │   ├── transcribe.py  #   mlx-whisper / faster-whisper
│   │   ├── transcript.py  #   таймкоды, блоки по 30 с, нарезка на части
│   │   ├── llm.py         #   Ollama, OpenAI-совместимые API, Claude (SDK Anthropic): стрим, отмена
│   │   ├── summarize.py   #   промпты, map-reduce, ссылки-таймкоды, шапка
│   │   └── export.py      #   .md / .docx / .pages, имена файлов, «открыть / показать»
│   ├── prompts/           # промпты по умолчанию
│   ├── templates/         # Jinja2-шаблоны страниц (+ partials для HTMX)
│   └── static/            # CSS, JS (app.js, player.js, htmx.min.js)
├── tests/                 # pytest; fakes.py — фейковые yt-dlp, Whisper, сервер LLM и SDK Anthropic
├── config.example.toml    # пример файла настроек
└── pyproject.toml         # зависимости и настройки pytest / ruff
```

### Тесты и линтер

uv run pytest          # тесты не ходят в сеть и не загружают модели

### JSON API

| Метод и путь | Что делает |
|---|---|
| `POST /api/jobs` | `{urls[], detail, language, model, force_whisper, format, out_dir}` → задачи |
| `GET /api/jobs` | список задач |
| `POST /api/jobs/{id}/cancel`, `/retry` | отменить / повторить |
| `GET /api/events` | поток SSE: `{job_id, status, stage, progress, message}` |
| `POST /api/videos/{id}/summaries` | переделать конспект (без Whisper) |
| `PUT /api/summaries/{id}` | `{markdown}` → новая версия |
| `POST /api/summaries/{id}/export` | `{format, out_dir}` → файл |
| `POST /api/exports/{id}/open`, `/reveal` | открыть файл / показать в папке |
| `DELETE /api/videos/{id}` | удалить из библиотеки |
| `GET /api/status`, `POST /api/models/pull` | проверки, скачивание модели |
| `POST /api/pick-folder` | системный диалог выбора папки |

Пример:

```bash
curl -X POST http://127.0.0.1:8765/api/jobs -H 'Content-Type: application/json' \
     -d '{"urls": ["https://youtu.be/VIDEO_ID"], "format": "md"}'
curl -N http://127.0.0.1:8765/api/events
```
