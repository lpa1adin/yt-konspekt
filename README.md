# YT-Конспект

**YT-Конспект** — локальное веб-приложение, которое делает конспект YouTube-видео. Вы вставляете ссылку,
а через несколько минут получаете структурированный конспект: краткое содержание, разделы с таймкодами,
ключевые термины и выводы. Клик по таймкоду перематывает видео в плеере рядом с конспектом.

Всё работает **на вашем компьютере**: текст видео берётся из субтитров YouTube или распознаётся локальной
моделью Whisper, конспект пишет локальная языковая модель через [Ollama](https://ollama.com)
(или LM Studio). Облачных API, регистрации и подписок нет. В интернет приложение ходит только к YouTube.

Сделано под Mac на Apple Silicon (M1–M4) с 16 ГБ памяти, работает также на Windows и Linux.

## Что умеет

- **Конспект по ссылке.** Одна или несколько ссылок сразу (по одной на строку): `youtu.be/…`, `watch?v=…`,
  `shorts/…`, `live/…`, `embed/…`.
- **Очередь задач с живым прогрессом.** Видно этап (субтитры → аудио → распознавание в % → «часть 3 из 8» →
  сохранение файла) и текст, который модель пишет прямо сейчас. Задачу можно отменить или повторить:
  повтор продолжает с места, где она остановилась.
- **Библиотека.** Все конспекты с обложками, полнотекстовый поиск по конспектам *и* расшифровкам
  с подсветкой совпадений, фильтры по каналу и дате.
- **Страница конспекта.** Слева конспект и вкладка «Расшифровка», справа плеер YouTube. Клик по таймкоду
  перематывает видео, текущий фрагмент расшифровки подсвечивается.
- **Переделка без повторного распознавания.** Можно пересоставить конспект другой моделью, на другом языке
  или в другой подробности: расшифровка уже сохранена, поэтому это занимает минуты.
- **Версии и ручная правка.** Каждая переделка и каждая ручная правка — новая версия, старые не теряются.
- **Экспорт** в `.md`, `.docx` и `.pages` (Pages — только macOS), кнопки «Открыть файл» и «Показать в папке».
  Таймкоды в файлах остаются рабочими ссылками на YouTube.
- **Экран «Состояние»** проверяет, всё ли установлено, подсказывает, как починить, и умеет скачать модель.

## Как это работает

```
ссылка
  │
  ├─ 1. yt-dlp: название, канал, длительность, список субтитров
  │
  ├─ 2. Текст видео
  │     ├─ есть субтитры → берём их (ручные на языке видео → ручные ru/en →
  │     │                  оригинальная автодорожка → автосубтитры)
  │     └─ нет субтитров → скачиваем аудио → Whisper large-v3-turbo
  │                        (mlx-whisper на Mac M, faster-whisper на остальных)
  │
  ├─ 3. Расшифровка → блоки по ~30 секунд вида «[мм:сс] текст»
  │
  ├─ 4. Локальная модель (Ollama, по умолчанию qwen3:8b) пишет конспект
  │     ├─ короткое видео → один запрос
  │     └─ длинное (> ~30–40 минут речи) → map-reduce: конспект каждой части,
  │        при необходимости сведение частей группами, затем итоговый документ
  │
  ├─ 5. Таймкоды [мм:сс] превращаются в ссылки https://youtu.be/ID?t=секунды,
  │     сверху добавляется шапка (видео, канал, длительность, модель, источник текста)
  │
  └─ 6. Конспект сохраняется в библиотеку и (если включено) в файл в выбранной папке
```

Важные решения внутри:

- **Задачи выполняются строго по одной.** Whisper (~2 ГБ) и языковая модель (~5–7 ГБ) никогда не работают
  одновременно — иначе на 16 ГБ не хватит памяти. После распознавания Whisper выгружается из памяти,
  а когда очередь пустеет, Ollama тоже освобождает модель.
- **Ничего не выдумывается.** Если в видео почти нет речи (музыка, расшифровка короче ~200 символов),
  задача останавливается с сообщением вместо фантазий модели. Промпт велит опираться только на расшифровку
  и исправлять очевидные ошибки распознавания.
- **Ссылки делает код, а не модель.** Модель пишет таймкоды как `[мм:сс]`, приложение превращает их в ссылки —
  так они всегда правильные.
- **Ничего не теряется.** Метаданные, расшифровка и уже готовые части конспекта сохраняются по ходу работы.
  Если задача упала на части 5 из 8 или Ollama была выключена, «Повторить» продолжит с пятой части.
- **Один процесс.** Сервер на FastAPI отдаёт страницы и API, фоновый воркер выполняет задачи,
  прогресс приходит в браузер через Server-Sent Events. Данные — в одном файле SQLite.

## Установка

Нужны: Python 3.11+, [uv](https://docs.astral.sh/uv/) (или обычный `venv`), ffmpeg, Ollama. Pandoc — по желанию.

### macOS

```bash
# 1. Системные программы
brew install ffmpeg pandoc uv

# 2. Ollama — приложение с ollama.com/download (или через Homebrew):
brew install ollama
brew services start ollama
ollama pull qwen3:8b          # ≈ 5 ГБ, один раз

# 3. Приложение
git clone https://github.com/lpa1adin/yt-konspekt.git
cd yt-konspekt
uv venv
uv pip install -e ".[dev]"
```

На Mac с процессором M автоматически ставится **mlx-whisper**, на остальных системах — **faster-whisper**.

- **ffmpeg** нужен для распознавания речи. Без него приложение переключится на faster-whisper.
- **pandoc** делает более аккуратный `.docx`. Без него работает встроенный конвертер (python-docx).
- **htmx** уже лежит в `app/static/js/htmx.min.js`. Если файла нет, страница загрузит его с CDN, а положить
  его в проект можно так:
  `curl -L -o app/static/js/htmx.min.js https://unpkg.com/htmx.org@2.0.4/dist/htmx.min.js`

### Windows

```powershell
winget install astral-sh.uv Git.Git Gyan.FFmpeg JohnMacFarlane.Pandoc Ollama.Ollama
ollama pull qwen3:8b
git clone https://github.com/lpa1adin/yt-konspekt.git
cd yt-konspekt
uv venv
uv pip install -e ".[dev]"
```

### Linux

```bash
sudo apt install git ffmpeg pandoc
curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen3:8b
git clone https://github.com/lpa1adin/yt-konspekt.git
cd yt-konspekt && uv venv && uv pip install -e ".[dev]"
```

### Без uv

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
```

## Запуск

Команды выполняются **из папки проекта** (там, где лежит `pyproject.toml`):

```bash
cd yt-konspekt
uv run python -m app
```

Откроется браузер на **http://127.0.0.1:8765**. Остановить — `Ctrl+C` в терминале.

Параметры запуска:

| Параметр | Что делает |
|---|---|
| `--port 8800` | другой порт |
| `--no-browser` | не открывать браузер автоматически |
| `--window` | открыть в отдельном окне, как приложение (нужно `uv pip install pywebview`) |

Сервер слушает только `127.0.0.1` — с других устройств в сети приложение недоступно.

> Если видите `No module named app` — вы запускаете не из папки проекта. Сначала `cd` в папку `yt-konspekt`.

### Режим командной строки

Без интерфейса и библиотеки — сразу в файл:

```bash
uv run python -m app.cli "https://youtu.be/VIDEO_ID" -o ~/Desktop/Лекции -f docx --detail short
```

Ключи: `-o` папка, `-f md|docx|pages`, `--detail full|short`, `--lang ru`, `-m qwen3:8b`,
`--whisper` (не брать субтитры), `--transcript` (сохранить и расшифровку), `--open` (открыть файл).

## Как пользоваться

1. **Первый запуск — экран «Состояние».** Пройдите пункты с красной отметкой сверху вниз. Если модели нет,
   нажмите «Скачать модель».
2. **«Новый конспект».** Вставьте ссылку и нажмите Enter (несколько ссылок — по одной на строку,
   новая строка — Shift+Enter). В свёрнутом блоке «Параметры» можно выбрать подробность, язык конспекта,
   модель, формат файла, папку (кнопка «Выбрать…» открывает системный диалог) и «Всегда распознавать речь
   Whisper».
3. **Ждите в карточке задачи.** Видно этап, прогресс и текст, который пишет модель. Время: видео с субтитрами —
   1–3 минуты; без субтитров добавляется распознавание (на Mac M примерно 1 минута на 10 минут видео).
4. **«Готово» → «Открыть».** Страница конспекта:
   - клик по таймкоду перематывает плеер справа;
   - вкладка «Расшифровка» — полный текст, текущий фрагмент подсвечивается («следовать за видео»);
   - **«Переделать»** — новая версия с другой моделью, языком или подробностью (без повторного Whisper);
   - **«Редактировать»** — правка в Markdown, сохраняется новой версией;
   - выбор версии — выпадающий список сверху;
   - **«Экспорт»**, «Показать в папке», «Удалить» (файлы на диске при удалении не трогаются).
5. **«Библиотека».** Поиск по любому слову из конспекта или расшифровки, фильтр по каналу и периоду.

Если ссылку на видео, которое уже есть в библиотеке, вставить ещё раз, приложение предупредит и предложит
открыть существующий конспект или всё же сделать новую версию.

## Настройка

Всё основное меняется на экране **«Настройки»**:

| Раздел | Что настраивается |
|---|---|
| Сохранение файлов | папка по умолчанию, формат, «сохранять файл сразу после готовности», шаблон имени (`{title}`, `{date} {title}`, `{channel}/{title}`), оставлять ли `.md` рядом, шаблон стилей `.docx` |
| Конспект | язык (по умолчанию русский), подробный или краткий |
| Локальная модель | сервер (Ollama или OpenAI-совместимый — LM Studio, llama.cpp), адрес, модель, контекст `num_ctx`, размер части `chunk_chars`, температура |
| Распознавание речи | движок (авто / mlx / faster), модель Whisper (large-v3-turbo / medium / small), язык речи, языки субтитров, брать ли субтитры YouTube, хранить ли аудио |
| YouTube | «Cookies из браузера» — если YouTube просит войти или подтвердить, что вы не бот |
| Промпты | тексты запросов к модели, у каждого — «Сбросить к умолчанию» |

### Выбор модели

Подходит любая модель из Ollama — список берётся из того, что у вас скачано. По умолчанию `qwen3:8b`:
хорошо пишет по-русски и помещается в 16 ГБ. На 32 ГБ и больше можно попробовать `qwen3:14b` или
`gemma3:12b` (скачать — на экране «Состояние» или `ollama pull имя`).

Для **LM Studio**: в LM Studio Developer → Start Server, в настройках выберите сервер «OpenAI-совместимый»
и адрес `http://localhost:1234/v1`.

### Длинные видео

`chunk_chars` (по умолчанию 18 000 символов ≈ 30–40 минут речи) — сколько текста уходит в один запрос.
Если появилось предупреждение «ответ обрезан», уменьшите это число и нажмите «Переделать».
`num_ctx` (по умолчанию 16 384 токена) — размер контекста модели; больше — точнее для длинных частей,
но больше памяти.

### Промпты

Лежат в `app/prompts/` и редактируются в «Настройках» (ваши правки хранятся в базе, файлы не меняются):

| Файл | Назначение |
|---|---|
| `system.md` | роль модели и общие правила |
| `full.md` | структура подробного конспекта (Кратко / Конспект / Ключевые термины / Выводы) |
| `short.md` | структура краткого конспекта (Кратко / Главное / Выводы) |
| `chunk.md` | конспект одной части длинного видео |
| `merge.md` | сведение частей группами |
| `final.md` | итоговый запрос (и для коротких видео) |

Переменные: `{title}`, `{language}`, `{transcript}`, `{i}`, `{n}`, `{structure}`.
Таймкоды просите писать как `[мм:сс]` — ссылки из них делает приложение.

### Файл config.toml (необязательно)

Настройки можно задать и файлом — например, чтобы перенести их на другой компьютер. Скопируйте
`config.example.toml` в папку данных под именем `config.toml` (пути — ниже). Порядок применения:
значения по умолчанию → `config.toml` → «Настройки» в интерфейсе → параметры конкретной задачи.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| `command not found: ollama` | Ollama не установлена — см. [Установка](#установка). |
| `No module named app` | Запускайте из папки проекта: `cd yt-konspekt`. |
| «Нет связи с сервером модели» | Запустите Ollama. Задача подождёт и продолжится сама (или нажмите «Проверить снова»). |
| «В Ollama нет модели …» | «Состояние» → «Скачать модель» или `ollama pull qwen3:8b`. |
| «YouTube просит подтвердить, что вы не бот» | `uv pip install -U yt-dlp`, затем в «Настройках» выберите «Cookies из браузера», где вы вошли в YouTube. |
| «Видео недоступно (закрытое или с возрастным ограничением)» | Та же настройка «Cookies из браузера». |
| «Сейчас идёт прямой эфир» | Дождитесь окончания эфира. |
| «Ответ модели обрезан» | Уменьшите «Размер части» и нажмите «Переделать». |
| «В видео почти нет речи» | Это музыка или видео без слов — конспект не выдумывается. |
| «Не удалось сохранить файл» | Конспект уже в библиотеке — «Экспорт» в другую папку. |
| Нет связи с YouTube | Приложение само повторяет 2 раза; потом — «Повторить». |

Подробности ошибки — кнопка «Подробнее» в карточке задачи и журнал `logs/app.log` в папке данных.

## Где хранятся данные

Данные лежат **вне папки проекта**:

| Что | Где |
|---|---|
| База (библиотека, расшифровки, версии, настройки, задачи) | `konspekt.sqlite3` в папке данных |
| Журнал | `logs/app.log` в папке данных |
| Временное аудио (удаляется после распознавания) | `cache/` в папке данных |
| Модели Whisper | кэш Hugging Face (`~/.cache/huggingface`) |
| Модели Ollama | `~/.ollama` |
| Файлы конспектов | выбранная папка, по умолчанию `~/Documents/Конспекты` |

Папка данных: macOS — `~/Library/Application Support/yt-konspekt`, Windows — `%LOCALAPPDATA%\yt-konspekt`,
Linux — `~/.local/share/yt-konspekt`. Другую можно указать переменной окружения `YT_KONSPEKT_DATA`.

## Для разработчика

### Структура проекта

```
yt-konspekt/
├── app/
│   ├── __main__.py        # python -m app → сервер + браузер
│   ├── main.py            # FastAPI: страницы и JSON API
│   ├── config.py          # настройки по умолчанию, config.toml, папка данных, журнал
│   ├── db.py              # SQLite (WAL) + полнотекстовый поиск FTS5
│   ├── jobs.py            # очередь и воркер: задачи строго по одной
│   ├── events.py          # шина событий для SSE
│   ├── status.py          # проверки экрана «Состояние»
│   ├── cli.py             # режим командной строки
│   ├── pipeline/          # шаги без БД и веба
│   │   ├── source.py      #   yt-dlp: ID, метаданные, субтитры, аудио, понятные ошибки
│   │   ├── transcribe.py  #   mlx-whisper / faster-whisper
│   │   ├── transcript.py  #   таймкоды, блоки по 30 с, нарезка на части
│   │   ├── llm.py         #   клиент Ollama и OpenAI-совместимого сервера (стрим, отмена)
│   │   ├── summarize.py   #   промпты, map-reduce, ссылки-таймкоды, шапка
│   │   └── export.py      #   .md / .docx / .pages, имена файлов, «открыть / показать»
│   ├── prompts/           # промпты по умолчанию
│   ├── templates/         # Jinja2-шаблоны страниц (+ partials для HTMX)
│   └── static/            # CSS, JS (app.js, player.js, htmx.min.js)
├── tests/                 # pytest; fakes.py — фейковые yt-dlp, Whisper и сервер LLM
├── config.example.toml    # пример файла настроек
└── pyproject.toml         # зависимости и настройки pytest / ruff
```

### JSON API

| Метод и путь | Что делает |
|---|---|
| `POST /api/jobs` | `{urls[], detail, language, model, force_whisper, format, out_dir}` → задачи |
| `GET /api/jobs` | список задач |
| `POST /api/jobs/{id}/cancel`, `/retry` | отменить / повторить |
| `GET /api/events` | поток SSE: `{job_id, status, stage, progress, message}` |
| `POST /api/videos/{id}/summaries` | переделать конспект (без Whisper) |
| `PUT /api/summaries/{id}` | `{markdown}` → новая версия |
| `POST /api/summaries/{id}/export` | `{format, out_dir}` → файл |
| `POST /api/exports/{id}/open`, `/reveal` | открыть файл / показать в папке |
| `DELETE /api/videos/{id}` | удалить из библиотеки |
| `GET /api/status`, `POST /api/models/pull` | проверки, скачивание модели |
| `POST /api/pick-folder` | системный диалог выбора папки |

Пример:

```bash
curl -X POST http://127.0.0.1:8765/api/jobs -H 'Content-Type: application/json' \
     -d '{"urls": ["https://youtu.be/VIDEO_ID"], "format": "md"}'
curl -N http://127.0.0.1:8765/api/events
```
